# Yalla City Standalone Prototype

نسخة مستقلة أولية لتجربة واجهة Yalla City من المتصفح.

## إعداد Firebase لاحقًا
1. أنشئ مشروع Firebase على خطة Spark.
2. فعّل Email/Password في Authentication.
3. أنشئ Cloud Firestore.
4. أضف إعدادات تطبيق الويب إلى firebase-config.js.
5. اضبط قواعد Firestore آمنة قبل السماح للاعبين باستخدام الشات والمزامنة.

ملاحظة: هذه مجلد نسخة مستقلة منفصل عن الخريطة الحالية. الخريطة المرسومة في النسخة التجريبية ليست بعد استيرادًا لخريطة WorkAdventure TMJ الأصلية.
